## 1. 定位

MVP 终验（2026-08-15）后的设计漂移轮（spec 中称「1.5 期」）：核心循环从「经验→四选一」重构为「银币→商店」经济，并补齐坚守模式、音效与 QoL。迭代编号 02（01 = MVP，见 `../../mvp/`）。

## 2. 触发来源

人工终验 7 条反馈（无坚守模式 / 攻击范围无感 / 移除更换武器改商店 / 无道具体验 / 僵尸量偏少 / 无 Esc 退出菜单 / 音效缺失）+ 用户补充漂移（撤销开局选枪、经验改银币、商店建筑、道具数字键、提前难度换银币）。

## 3. 决策记录（2026-08-15，用户裁定）

| # | 决策点 | 裁定 |
|---|---|---|
| 1 | 商店交互 | 地图建筑实体，走近自动唤出面板并暂停；商品三类：增强 / 更换武器 / 道具 |
| 2 | 升级体系 | **彻底移除**四选一与经验条；击杀只掉银币；增强含伤害/攻速/弹道/**攻击范围**（用户裁定保留，价格统一递增） |
| 3 | 提前难度 | 玩家主动触发 + 奖励：`floor(当前档剩余秒 / 30) × 25` 银币；时间轴快进到下一档起点 |
| 4 | 道具使用 | 数字键 1–9 战斗中直接使用，不暂停（本轮 3 槽：1 医疗包 / 2 磁铁 / 3 炸弹） |
| 5 | 实施范围 | 终验 7 条**全部一次做完**（含坚守 10/20、守门 Boss、CC0 音效、Esc 菜单、僵尸量上调） |
| 撤销 | 「游戏开始前选择武器」 | **撤销**——开局固定手枪 |
