## 2. 人工终验清单

运行方式：`npx serve .` → 浏览器打开（默认 http://localhost:3000）→ F12 观察 console。标签指示条目来源分册（执行期的完整措辞见对应分册 Step）。

### A. 全流程终验（spec §12 MVP 标准）［08 · Task 16 Step 10］

- [ ] 打开即主菜单：标题、『无尽模式』按钮、最佳纪录文案（首局『暂无纪录』）
- [ ] 选『无尽模式』进入战斗：WASD/方向键移动（斜向不加速、边界夹紧、障碍阻挡滑动）
- [ ] 武器自动索敌射击：命中闪白 / 伤害数字 / 击退可见
- [ ] 僵尸自四周环形屏幕外涌入并持续追踪，新手保护期后规模渐增
- [ ] 击杀掉落经验球，靠近自动磁吸拾取
- [ ] 升级弹出四选一，点选即时生效（伤害/攻速/弹道/范围提升可感）
- [ ] **更换武器卡生效回归**：点选后开火手感立即切换（伤害/射速变化），HUD 与 build 栏同步［07 · Task 14］
- [ ] 血量归零 → 结算界面（存活时长/击杀数/等级），破纪录显示『新纪录！』
- [ ] 『再来一局』完整重开；『回主菜单』后纪录文案已更新
- [ ] 纪录写入 localStorage，刷新页面仍在
- [ ] 全程 console 无报错、帧率稳定（同屏僵尸 ≤300 / 弹 ≤400 / 粒子 ≤500 预算内不卡顿）

### B. 战斗场景细节回归［07 · Task 14 Step 2］

- [ ] 障碍物阻挡：玩家与僵尸均被圆/矩形障碍挡住并沿边滑动
- [ ] 被僵尸咬中扣血（血条变短）且有震屏
- [ ] 升级时游戏暂停（僵尸静止），选卡后继续；连升多级依次弹卡直至归零
- [ ] 死亡瞬间画面静止，结算数据正确

### C. 升级界面与 HUD［08 · Task 15 Step 7］

- [ ] 覆盖层含 build 栏（武器名 + Lv + 四维增强次数），点卡后即时刷新
- [ ] 卡片文案正确：武器强化/更换武器/急救包三类（必要时 heal 兜底填充）
- [ ] HUD：左上血条+数值、其下经验条+Lv、右上计时(MM:SS)+难度档+击杀数、左下武器信息
- [ ] 难度档数字在整 180 秒跨档；经验条拾取时增长

### D. 菜单/结算/存档状态机［08 · Task 16 Step 8］

- [ ] 菜单 → 战斗 → 结算 → 再来一局/回菜单 全循环无残留状态（时间归零、僵尸清空、经验重置）
- [ ] localStorage 不可用（隐私模式）时不报错、静默降级

## 3. 性能验收

- 中端笔记本稳定 60fps（F12 帧率或目测）
- 上限不击穿：同屏僵尸 ≤300（spawner 强制）、子弹 ≤400、粒子 ≤500、伤害数字 ≤100（G§6；离屏剔除未实现属已知裁剪 G§7.6）
