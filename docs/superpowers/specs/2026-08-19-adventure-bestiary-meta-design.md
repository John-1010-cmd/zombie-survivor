### 已确认的关键决策（逐题确认记录）

- 冒险为**第 4 个独立入口**，旧模式代码保留；主菜单最终入口：**冒险 / 无尽 / 图鉴 / 武器升级**（坚守 10/20 分钟从菜单移除，代码不删，可随时恢复）
- 冒险一局 = **4 档 × 90s = 6 分钟，纯时间推进，撑到底即通关**，无强制 Boss；首批 **3 关**，曲线按可无限追加设计
- 图鉴为**完整图鉴系统**：游戏内查看界面 + 遭遇解锁 + 击杀统计 + 数值详情
- 怪物新数值公式**应用到全部模式**（旧模式映射为"关卡 1"，重调平衡）
- 金币获取：**通关奖励为主（首通 ×2）+ 失败保底 + 开发者菜单**；用途**仅限武器局外升级**，经济系统预留其他消耗口
- 局内商店强化：**只改伤害维**为百分比制，攻速/弹道/范围/专属维维持现状
- 视觉：**Infinitode 2 几何矢量风**，纯 Canvas 2D 绘制，不引图片资源
- UI **全面翻新**（含现有 HUD/商店/暂停/结算统一重排）
- 本次新增怪/武器**各 1 种**验证图鉴扩展性：自爆僵尸（新机制挂钩）、狙击枪（纯数值）
- 架构方案 A：**数据注册表 + 行为注册表分离**

## 2. 统一数值管线（scaling.js）

纯函数，无 DOM 依赖，全模式共用。

### 2.1 怪物数值

```
最终值 = 图鉴基础 × 关卡倍率 × (1 + 局内分钟 × 增长率)
```

- **关卡倍率**（局外，随冒险关卡数递增）：
  - hp / damage：`× (1 + 0.6 × (关卡数 - 1))` → 关 1 ×1.0、关 2 ×1.6、关 3 ×2.2
  - speed：`× (1 + 0.05 × (关卡数 - 1))`，移速只微涨，避免手感突变
  - 无尽/坚守模式映射为"关卡 1"，关卡倍率恒 1
- **局内增长率**（局内，随游戏时间连续递增，替代旧阶梯 hpMult/speedMult）：

| 参数 | 无尽/坚守 | 冒险 | 说明 |
|------|----------|------|------|
| hp 增长率 | +45%/分钟 | +35%/分钟 | 无尽 21 分钟时 ≈ ×10，与旧表第 8 档平滑衔接；冒险通关时 ≈ ×3.1 |
| damage 增长率 | +22.5%/分钟 | +17.5%/分钟 | hp 率的一半 |
| speed 增长率 | +2%/分钟 | +1.5%/分钟 | 固定小率 |

- 旧 `DIFFICULTY_TIERS` 的 `hpMult`/`speedMult` 字段退役；`budgetPerSec`/`weights`/`unlocks` 保留（刷怪节奏仍由难度表控制）
- 银币掉落沿用现有递增逻辑（`基值 × min(4, 1 + 0.25×(档位-1))`），改从管线读取

接口（示意）：

```js
calcMonsterStats(baseStats, { levelMult, timeSec, modeParams }) → { hp, speed, damage }
getModeScaling(modeId) → { hpRatePerMin, dmgRatePerMin, speedRatePerMin }
```

### 2.2 武器数值

```
最终伤害 = 图鉴基础 × (1 + 0.2 × 局外等级) × (1 + 0.25 × 局内购买次数)
```

- **局外乘区**（金币升级）：每把武器独立 0–10 级，每级 +20% 图鉴基础伤害
- **局内乘区**（银币强化）：商店伤害条目每购一次 +25%，乘在局内乘区；换武器时重置（与现规则一致）
- 攻速/弹道/范围/专属维（榴弹碎片、磁电链路）维持现有固定值强化逻辑不变

## 3. 冒险关卡模式

### 3.1 结构

- 一局 = 4 档 × 90s = 360s；纯时间推进，撑满即通关，中途死亡即失败
- 通关第 N 关解锁第 N+1 关；初始仅第 1 关解锁
- 关卡选择页显示：名称、解锁状态（锁定显示 ???）、最佳成绩（存活时间/通关标记）

### 3.2 关卡配置表（config/adventure.js）

每关：`{ id, name, tiers: [4 × { duration: 90, budgetPerSec, weights, unlocks }], goldReward }`

**关 1「城郊」**（goldReward: 100）

| 档 | 预算/秒 | 权重 |
|----|--------|------|
| 1 | 3 | 普通 100% |
| 2 | 4.5 | 普通 70% / 高速 30% |
| 3 | 7 | 普通 60% / 高速 40% |
| 4 | 9 | 普通 50% / 高速 30% / 坦克 20% |

**关 2「市区」**（goldReward: 160）

| 档 | 预算/秒 | 权重 |
|----|--------|------|
| 1 | 4 | 普通 80% / 高速 20% |
| 2 | 6 | 普通 60% / 高速 40% |
| 3 | 8.5 | 普通 50% / 高速 30% / 坦克 20% |
| 4 | 11 | 普通 40% / 高速 35% / 坦克 25% |

**关 3「巢穴」**（goldReward: 240）

| 档 | 预算/秒 | 权重 |
|----|--------|------|
| 1 | 5 | 普通 70% / 高速 30% |
| 2 | 7.5 | 普通 50% / 高速 35% / 坦克 15% |
| 3 | 10 | 普通 40% / 高速 35% / 坦克 25% |
| 4 | 13 | 普通 30% / 高速 30% / 坦克 25% / 自爆 15% |

### 3.3 跨关递进（三个杠杆同时加）

1. **种类组合更激进**：高关卡更早混入高速/坦克，关 3 档 4 引入自爆僵尸
2. **刷怪预算**：上表数值已含跨关递增（同档位对比关 1→3 约 ×1.5）
3. **怪物数值**：走 §2.1 关卡倍率（hp/伤害关 2 ×1.6、关 3 ×2.2）

### 3.4 金币奖励

- 通关：`goldReward`；**首通 ×2**（meta 存档记录首通标记）
- 失败保底：`goldReward × (存活秒数 / 360) × 50%`，按 round5 取整到 5 的倍数（与银币经济风格一致）
- 结算页展示：胜/负、存活时间、击杀数、本局金币（含首通标记），可重开或回关卡选择

## 4. 怪物图鉴（config/bestiary/monsters.js）

### 4.1 数据结构

```js
normal: {
  id: 'normal', name: '普通僵尸', desc: '图鉴描述文本',
  // —— 基础数值（现有字段原样迁移）——
  hp: 30, speed: 70, damage: 8, coin: 1,
  radius: 14, knockbackResist: 0, cost: 1,
  // —— 图鉴新增 ——
  visual: { shape: 'circle', color: '#6a8f6a', glow: 0.3 },  // 渲染描述，见 §9
  behavior: null,   // null = 默认追击 AI；否则为 behaviors.js 的注册 id
}
```

### 4.2 行为注册表（systems/behaviors.js）

```js
export const BEHAVIORS = {
  exploder: {
    onUpdate(z, dt, ctx) { /* 接近玩家开始 1.2s 引信，闪烁膨胀 */ },
    onDeath(z, ctx)      { /* 自爆：范围伤害 + 冲击波特效 */ },
  },
};
```

- 钩子命名约定：`onSpawn / onUpdate / onHit / onDeath`，zombie 实体在对应时机调用；`behavior: null` 时全部跳过
- **新增种类的方式**（开发向，写进文件头注释）：
  - 换皮换数值：图鉴加一条数据即可，`behavior: null`
  - 新机制：在 behaviors.js 注册行为模块 + 图鉴条目声明 `behavior` 字段

### 4.3 新怪：自爆僵尸（kamikaze）

`{ hp: 40, speed: 90, damage: 5（接触）, coin: 3, radius: 13, behavior: 'exploder', visual: { shape: 'diamond', color: 橙 } }`
自爆 AoE：半径 80、伤害 30（**AoE 伤害与接触 damage 同乘区**，随 §2.1 关卡倍率与局内时间增长率缩放），对玩家与围墙生效；引信 1.2s，期间闪烁膨胀。首次出现在冒险关 3 档 4；无尽模式第 5 档起加入权重。

## 5. 武器图鉴（config/bestiary/weapons.js）

## 6. 金币经济与武器局外升级

### 6.1 金币

- 来源：冒险通关奖励（首通 ×2）、失败保底、开发者菜单（+1000）
- 存储：`core/meta.js`，localStorage 独立 key，带版本号
- 用途：仅武器局外升级；经济函数保持通用签名（`meta.spendGold(n)`），预留其他消耗口

### 6.2 武器升级（局外）

- 每把武器独立 0–10 级；每级伤害 +20% 图鉴基础（见 §2.2 公式）
- 升级价：`round5(40 × 1.5^当前等级)` 金币；升满累计约 4500 金币
- 升级界面（ui/upgrades.js）：武器列表展示当前等级、下一级提升幅度、价格；金币余额常驻；不够时按钮置灰

## 7. 图鉴界面（ui/bestiary.js）

- 主菜单「图鉴」入口，内分「怪物」「武器」两个标签页
- **怪物页**：网格陈列所有种类；未解锁的显示 `???` 剪影；**首次击杀后解锁**（`meta.bestiaryKills[id] ≥ 1` 即视为遭遇）形象与名称；条目详情 = 基础数值 + 描述 + 累计击杀数（`meta.bestiaryKills` 持久化，击杀时计数）
- **武器页**：全部可见；条目 = 描述 + 基础数值 + 当前局外等级，与升级界面联动高亮

## 8. UI 全面翻新

- **统一视觉语言**：深色底 + 霓虹几何描边面板，与怪物/子弹的几何矢量风一致；统一按钮、面板、间距、字号规范，`style.css` 重建
- **主菜单四入口**：冒险 / 无尽 / 图鉴 / 武器升级（坚守 10/20 分钟从菜单移除，代码与 `MODES` 配置保留）
- **新界面**：关卡选择（卡片式）、武器升级、图鉴（§7）
- **现有界面重排**（风格统一，信息层级不变）：
  - HUD：冒险模式顶部加四档进度条（当前档高亮 + 档内进度）；金币是局外货币，不进局内 HUD
  - 商店、暂停、结算：套用新风格
- **结算页**：冒险模式含金币结算区（见 §3.4）

## 9. 视觉方向（Infinitode 2 几何矢量风）

纯 Canvas 2D 绘制，不引图片资源。

### 9.1 怪物造型

| 怪 | 形状 | 主色 |
|----|------|------|
| 普通 | 圆形 | 墨绿 |
| 高速 | 三角形 | 黄 |
| 坦克 | 六边形 | 红褐 |
| Boss | 大五边形 | 暗红 |
| 自爆 | 菱形（引信期闪烁膨胀） | 橙 |

- 统一细节：发光描边、受击闪白、受伤后才显示的血条、死亡碎裂粒子
- 形状画法注册在渲染器（`shape id → 绘制函数`），新怪加形状 = 注册一个多边形画法 + 图鉴 `visual.shape` 引用

### 9.2 子弹特效（每武器独特弹道语言）

- 弹体为发光几何体：手枪小圆点 / 步枪长条弹 / 机枪短点散射 / 火箭·榴弹带尾焰多边形 / 磁电枪链状电弧 / 狙击细长光针
- 发光拖尾（additive 渐隐轨迹）+ 命中粒子喷溅 + AoE 冲击波圆环 + 枪口闪光
- 参数全部来自武器图鉴 `visual` 字段；`entities/effects.js` 扩展为带对象池的粒子系统

### 9.3 性能红线

- 同屏 400 怪 + 弹道粒子保持流畅：粒子全局上限、拖尾用定长线段数组、禁止每帧对象分配（沿用 `core/pool.js`）
